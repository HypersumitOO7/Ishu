UPLOAD TO GITHUB (ANDROID)
1. Extract this ZIP on your phone.
2. In your GitHub repository, open Add file -> Upload files.
3. Upload index.html, music.mp3, and the photos folder (with all four images).
4. Commit directly to main. If GitHub asks to replace index.html, choose replacement.
5. Wait for the GitHub Pages deployment to finish.

IMPORTANT SETTINGS
- Preview mode is currently ON so you can test the chapters immediately.
- Before sharing with Ishika, open index.html, find previewMode:true and change it to previewMode:false, then commit the change.
- Music is attempted automatically after the visitor taps “Let's begin our journey”. Mobile browsers block audible autoplay before a user gesture; the floating player also has a play/pause control.
- The song file is bundled locally as music.mp3; no YouTube player is used.
