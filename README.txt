ISHIKA 11:11 — YOUTUBE MUSIC VERSION

This version embeds the YouTube video:
https://youtu.be/oqXG7Nzx68g

To publish:
1. In your GitHub repository, open Add file -> Upload files.
2. Upload this index.html and replace the existing file.
3. Commit directly to main.
4. Wait for GitHub Pages to redeploy.

The embedded YouTube player is visible near the bottom-right of the page. Ishika must tap Play herself; browsers generally block autoplay. YouTube may show ads and its own player controls. This embeds the video; it does not extract or download the song as an MP3.

Preview mode is currently true. Before sharing the site, set CONFIG.previewMode to false in index.html and commit again. The website is public and preview mode is not secure access control.
